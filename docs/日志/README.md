# 开发日志

按天记录：**做了什么、遇到什么问题、怎么解决的、做了什么决定。**

## 为什么记

- 卡过的问题，三天后还会再卡一次
- "当时为什么这么设计"——三个月后只有这份日志能回答
- 论文里"方法演进"那一节，素材全在这里

## 格式

每天一个文件：`YYYY-MM-DD.md`，固定四节：

1. **今天做完的** —— 能跑起来的东西，不是"写了什么"
2. **问题与解决** —— 现象 → 原因 → 解法，三行就要能看懂
3. **决定** —— 选了 A 不选 B，为什么
4. **明天** —— 下一步 + 卡在哪
