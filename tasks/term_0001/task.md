# 整理 downloads 目录

`downloads/` 里堆了一堆文件，请按类型分门别类。

## 分到哪

| 目标目录 | 收哪些扩展名 |
|---|---|
| `images/` | jpg、jpeg、png、gif、webp |
| `docs/` | pdf、txt、doc、docx |
| `videos/` | mp4、mov、avi |
| `others/` | 上面都没提到的 |

## 注意

- 扩展名**不区分大小写**（`.JPG` 和 `.jpg` 算同一类）
- **以 `.` 开头的隐藏文件不要动**
- **`README.md` 不要动**（它是说明文件，不属于任何一类）
- 目标目录不存在就自己建
- 分完之后 `downloads/` 里只该剩那两个不该动的文件
