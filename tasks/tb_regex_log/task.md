# 写一个正则，从日志里提取日期

写一个正则表达式，匹配**同时满足**下面条件的日期：

1. 格式是 `YYYY-MM-DD`
2. 所在的那一行里**含有一个合法的 IPv4 地址**
3. 如果一行里有多个日期，**只匹配最后一个**

## 细节要求

- 二月按最多 29 天算，**不区分闰年**
- IPv4 是标准十进制写法，每段**不带前导零**
- 日志里可能有长得像日期或 IPv4 但**不是**的文本（比如 `user 1134-12-1234`）
- **合法的日期和 IPv4 前面、后面都不能紧挨着字母或数字**（避免误匹配）

## 交什么

把正则写进 `regex.txt`，放在工作区根目录。

判据会这样用它：

```python
import re

with open("regex.txt") as f:
    pattern = f.read().strip()

matches = re.findall(pattern, log_text, re.MULTILINE)
```

注意 `re.findall` 的行为：如果正则里有捕获组，它只返回捕获到的内容。
