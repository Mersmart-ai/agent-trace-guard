# 表格里要显示原始字节数

`render_table()` 渲染出来的表格，大小那一列现在只有 `1.5 KB` 这种。

产品要求在这一列后面附上原始字节数，变成这样：

```
a          1.5 KB (1536 B)
x          12 B (12 B)
```

## 要求

```python
render_table([("a", 1536)])   # → "a          1.5 KB (1536 B)"
render_table([("x", 12)])     # → "x          12 B (12 B)"
```

## 注意

- 只改 `src/` 下的代码
- 不要改测试
- 改完必须全部测试通过
