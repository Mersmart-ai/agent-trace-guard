# format_size 改成单位表驱动

现在 `formatter.format_size()` 是一串 if。再加 TB 又要加一个分支，越来越长。

请改成用一张表驱动：

```python
UNITS = [("TB", 1024 ** 4), ("GB", 1024 ** 3), ("MB", 1024 ** 2), ("KB", 1024)]
```

遍历这张表，找到第一个"值不小于该单位"的档位。

## 要求

- 加 TB 支持（`1024**4` 输出 `1.0 TB`）
- **输出格式必须和现在完全一致**：B 档不带小数（`12 B`），其他档一位小数（`1.5 KB` / `1.0 MB` / `1.0 GB`）
- 只改 `src/` 下的代码
- 改完测试要过
